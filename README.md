# Heart Nebula — открытка

Одностраничный сайт-открытка: дымное сердце-туманность, звёздное небо, дальние космические объекты,
тёплый эмбиент (орган + пианино), стук сердца и «секретные» строки по клику на сердце.
Без сборки, без зависимостей, без интернета — просто открой `index.html`.

## Как открыть

Двойной клик по `index.html` — откроется в браузере.

Если хочется локальный сервер (удобно для правок):

```powershell
cd D:\Project\heart-nebula
python -m http.server 8137
```

Потом открыть `http://127.0.0.1:8137`.

## Как поменять текст

В начале `<script>` внутри `index.html` есть блок `CONFIG`:

```js
const CONFIG = {
  name: "Катя",      // например "Катя" — добавится в заголовок
  title: "Для тебя",
  message: [
    "Ты — моя вселенная.",
    "Я люблю тебя больше, чем звёзд на небе."
  ],
  signature: "Твой Гера",
  // эти строки появляются по клику на сердце (по очереди)
  secrets: [
    "{name}, ты — моё самое красивое чудо.",
    "В каждой вселенной я снова выбираю тебя.",
    "Ты сияешь ярче, чем все звёзды вместе."
  ]
};
```

- `name` — если вписать имя, заголовок станет «Для тебя, Катя»; `{name}` в `secrets` подставит это же имя.
- `message` — массив строк, каждая строка с новой строки.
- `signature` — подпись внизу.
- `secrets` — строки-сюрпризы: каждое нажатие на сердце показывает следующую.

Больше ничего трогать не нужно.

## Как отправить

Варианты:

1. **Файлом** — отправить `index.html` в Telegram/WhatsApp. Получатель открывает файл в браузере.
2. **Ссылкой** — залить папку на любой статический хостинг:
   - GitHub Pages,
   - Netlify Drop (перетащить папку),
   - Cloudflare Pages.
   Дальше просто отправить ссылку.

Для телефона лучше отправлять ссылку: файл в мессенджере может открыться не в браузере, а во встроенном просмотрщике.

## Что внутри

- Звёздное небо с параллаксом от мыши и редкими падающими звёздами.
- Дымное сердце-туманность: два слоя фрактального шума (soft-light), большие медленно закручивающиеся облака,
  цветовые волны внутри, пыль, пряди, волокна и звёздные сгустки.
- Дальние объекты на фоне: спиральная галактика, планета с кольцом и луной, цветные туманные пятна.
- Яркая звезда в центре, которая вспыхивает при открытии.
- После кнопки «Открыть»: сердце вырастает, бьётся, от него идёт звёздный ветер и круговые волны.
- **Клик по сердцу** — сердце сильно вздрагивает, летят кольца, вспышка, вверх всплывают маленькие сердечки,
  звучит нежный перезвон и появляется строка-сюрприз. Кликов можно делать сколько угодно — строки идут по кругу.
- Эффекты мыши: параллакс звёзд, звёздная пыль за курсором и мягкое расступление звёзд. Сердце и его «волоски» при движении мыши не смещаются.
- Звук: очень тихий эмбиент — органные пады (Amaj9 → F#m9 → Dmaj9 → E6/9) с длинным ревербом
  и редкие мягкие ноты пианино; стук сердца специально слышно намного громче музыки.
- Интро с кнопкой «Открыть», кнопка звука справа сверху, подсказка «нажми на сердце».
- Оптимизации: туманность перерисовывается ~24 fps, уменьшены частицы/звёзды и разрешение рабочих канвасов.
- Адаптив под телефон, `prefers-reduced-motion` уважается.

## Настройки визуала

- Цвета — CSS-переменные `--pink`, `--violet`, `--cyan` в начале `<style>`.
- Палитра туманности — массивы `SIDE_COOL`, `SIDE_WARM`, `SIDE_MID` в скрипте.
- Степень рваности края — `EDGE_SEEDS` (амплитуды `amp`) и `edgeNoise()`.
- Дымность — `buildNoise()` (октавы шума) и его отрисовка в `drawNebula()` (альфа слоёв `soft-light`).
- Количество частиц — `count` в `buildParticles()`.
- Клочья, пряди, волокна, сгустки и «укусы» — `buildTufts()`, `buildTendrils()`, `buildFilaments()`, `buildKnots()`, `buildBites()`.
- Дальние объекты — `buildSpaceObjects()` и `buildGalaxySprite()`, отрисовка — `drawSpaceObjects()`.
- Падающие звёзды — `spawnMeteor()` / `drawMeteors()` (частота — `nextMeteor`).
- Реакция на клик по сердцу — `heartReaction()`, `spawnHearts()`, `heartContains()`.
- Сила эффектов мыши — `pointermove`, `drawStars()`, `drawTrail()`, `drawCursorGlow()`.
- Размер сердца — `R` в функции `resize()`.
- Громкость музыки и сердца — `MUSIC_LEVEL` и `HEART_LEVEL`; аккорды — `CHORDS`, орган — `playPad()`,
  пианино — `playPluck()`, перезвон — `chime()`, стук — `thump()`.
- Если нужен более спокойный вариант — уменьши `amp` в `EDGE_SEEDS` и количество элементов в `build*()`.
